2. WHAT R8N18 ADDED
============================================================

R8N18 adds Phase 1 of the real RingCentral-connected power dialer:

- Admin campaign creation from phone numbers on existing uploaded accounts
- Portfolio/client, employee, balance, state, status, last-call, attempt, and
  schedule filters
- One Co Pilot employee mapped to one RingCentral user and extension
- Per-employee RingCentral user JWT lookup from LIVE Edge Function Secrets
- Employee Available, Unavailable, Dialing, Connected, and Wrap-Up states
- Server-side compliance check immediately before every call
- One call per available employee
- RingOut provider call creation
- One telephony-session webhook subscription per connected employee user
- Answer/disconnect event processing
- Supabase Realtime account screen pop into the existing browser tab
- Live connected banner and timer
- Mandatory disposition before another call
- Existing account call-result/activity integration
- Admin Start, Pause, Resume, Stop and live campaign/agent views

New database objects:

- ringcentral_user_mappings
- dialer_campaigns
- dialer_campaign_accounts
- dialer_agent_status
- dialer_calls
- dialer_screen_pops
- ringcentral_webhook_subscriptions

New Edge Functions:

3. PRIVATE PROVIDER CONFIGURATION
============================================================

RingCentral private values remain only in LIVE Supabase Edge Function Secrets:

- RC_APP_CLIENT_ID
- RC_APP_CLIENT_SECRET
- RC_USER_JWTS_JSON
- RC_WEBHOOK_VALIDATION_TOKEN
- Optional RC_SERVER_URL
- Single-user test fallback only: RC_USER_JWT + RC_DEFAULT_USER_EMAIL

RC_USER_JWTS_JSON is keyed by exact lowercase Co Pilot employee email. Never
reuse one employee's RingCentral JWT for another employee.

Read R8N18_RINGCENTRAL_SETUP.txt before deployment or troubleshooting.

============================================================
4. CURRENT LIMITS
============================================================

R8N18 is a power dialer, not a predictive dialer or voice broadcaster.
It does not yet include:

- Multiple simultaneous calls per employee
- Answering-machine/voicemail detection
- Prerecorded voice broadcasts
- Press-1 live transfer campaigns
- Automated voicemail drops
- Predictive pacing or abandoned-call controls

Those belong to later phases only after Phase 1 live provider behavior,
screen pops, compliance, reports, and dispositions are verified.
