R8N19.18 RECORDED VOICE MESSAGE INSTALL

1. Run R8N19-18-SQL-COPY-PASTE.txt once in Supabase SQL Editor.
2. Replace root index.html in GitHub.
3. Add voice-recording.js to the GitHub root beside index.html and screen-pop.js.
4. Replace the existing voice-broadcast-webhook Edge Function with voice-broadcast-webhook-R8N19-18-COPY-PASTE.txt and deploy. Keep Verify JWT OFF for the webhook.
5. No change is required to voice-broadcast for audio playback, but a complete copy is included for consistency.
6. Publish, then clear Netlify cache and deploy. Hard refresh the live site.

USE
Open Voice Broadcast > Campaigns. Under Live Person Message choose Recorded Voice. Record from the browser microphone or upload an MP3/WAV. Preview, save, then create the campaign.

The recording is encoded as a Twilio-compatible WAV and stored in the public voice-broadcast-audio bucket. Twilio uses <Play> for recorded campaigns and keeps <Say> for text-to-speech campaigns.
