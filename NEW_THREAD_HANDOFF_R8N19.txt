DIALER DIRECTION CORRECTION
===========================
R8N18 attempted a per-employee RingCentral power dialer and required individual RingCentral JWT credentials.
That did not match the user's intended TMax-style workflow.

R8N19 replaces the visible dialer with:
Uploaded accounts → Twilio voice broadcast → human answer/Press 1 → RingCentral group number → first collector answers.

R8N19 does not use employee RingCentral credentials, extensions, or employee forwarding numbers.
The old R8N18 database tables may still exist if its SQL was run, but the R8N19 frontend and functions do not use them.

R8N19 PROVIDER ARCHITECTURE
===========================
Twilio Programmable Voice:
- Initiates outbound calls from uploaded Co Pilot account phone numbers.
- Performs human/machine detection.
- Plays text-to-speech messages.
- Optionally gathers Press 1.
- Transfers qualified live calls to one RingCentral queue number.
- Sends signed webhooks for call and transfer outcomes.

RingCentral:
- Receives one transferred call at the public call-queue/group number.
- Rings queue members according to RingCentral queue settings.
- First collector to answer gets the call.

Required LIVE Supabase secrets:
- TWILIO_ACCOUNT_SID
- TWILIO_AUTH_TOKEN
- TWILIO_FROM_NUMBER

New Edge Functions:
- voice-broadcast
- voice-broadcast-webhook

New incremental SQL:
- SQL_TO_RUN_IN_SUPABASE/R8N19_SIMPLE_VOICE_BROADCAST.sql

New tables:
- voice_broadcast_settings
- voice_broadcast_campaigns
- voice_broadcast_campaign_accounts
- voice_broadcast_calls

OPERATING LIMITATION
====================
The R8N19 campaign pump runs while the admin Broadcast page is open. Closing the page stops launching new calls. Active calls can complete. A future release may replace this with a server-side scheduler/worker after the simple workflow is proven.
